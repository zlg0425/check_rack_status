# 测试脚本总结

本文档总结了项目中已创建的自动化测试脚本和测试数据。

## 已创建的测试脚本

### 1. 上传功能测试

#### `test_upload_automated.py`
- **功能**: 测试单个文件上传的各种场景
- **测试用例数**: 10个
- **覆盖场景**:
  - 正常文件上传
  - 大文件上传（5MB）
  - 文件覆盖上传
  - 路径验证（防止路径遍历攻击）
  - 磁盘空间检查
  - 文件存在检查
  - 特殊字符文件名
  - 空文件上传
  - 隐藏文件上传
  - 进度回调功能

#### `test_batch_upload_automated.py`
- **功能**: 测试批量上传功能的各种场景
- **测试用例数**: 7个
- **覆盖场景**:
  - 基本批量上传（单文件多服务器）
  - 多文件批量上传
  - 单文件多服务器批量上传
  - 空文件批量上传
  - 大文件批量上传
  - 无效参数测试
  - 进度跟踪测试
- **注意**: 需要 `web_ui.py` 正在运行

### 2. 下载功能测试

#### `test_download_unified.py`
- **功能**: 统一的下载功能测试脚本，支持函数调用和API调用两种模式
- **测试用例数**: 
  - 函数模式：8个
  - API模式：11个
- **覆盖场景**: 参考 `docs/download_documentation.md`
- **测试方式**: 
  - `--mode function`: 直接调用 `sftp_download` 函数
  - `--mode api`: 通过HTTP请求测试API端点
- **优势**: 
  - 统一接口，代码复用
  - 通过参数切换测试模式
  - 自动检测API服务器（API模式）
- **注意**: API模式需要 `web_ui.py` 正在运行

## 快速开始

### 运行上传测试

```bash
# 单文件上传测试
python test_upload_automated.py

# 批量上传测试（需要先启动web_ui.py）
python web_ui.py  # 在另一个终端
python test_batch_upload_automated.py
```

### 运行下载测试

```bash
# 函数测试（不需要web_ui.py）
python test_download_unified.py --mode function

# API测试（需要先启动web_ui.py）
python web_ui.py  # 在另一个终端
python test_download_unified.py --mode api
```

## 测试脚本特性

### 共同特性

1. **命令行参数支持**
   - `--server`: 指定服务器名称
   - `--ip`: 指定服务器IP
   - `--port`: 指定端口（默认22）
   - `--test`: 运行特定测试用例
   - `--keep-temp`: 保留临时文件（仅单文件上传测试）

2. **自动清理**
   - **所有测试脚本都会在测试完成后自动清理远程测试目录**
   - 清理功能会递归删除测试目录及其所有内容
   - 清理失败会显示警告，但不会影响测试结果

3. **详细输出**
   - 每个测试用例的详细执行信息
   - 测试结果摘要
   - 错误信息（如果失败）

4. **退出码**
   - `0`: 所有测试通过
   - `1`: 有测试失败

### 批量上传测试特殊特性

- **Web服务依赖**: 需要 `web_ui.py` 正在运行
- **HTTP API测试**: 通过HTTP API进行测试，而不是直接调用函数
- **进度跟踪**: 支持实时进度跟踪（SSE）
- **并发测试**: 测试并发上传多个文件到多个服务器

## 注意事项

1. **测试环境**
   - 需要配置 `config.json` 中的服务器信息
   - 需要能够访问配置的服务器
   - 批量上传测试需要Web服务运行

2. **测试数据**
   - 测试数据已预创建在 `test_data/` 目录
   - 大文件（5MB）已创建，可能需要一些时间

3. **远程目录**
   - 测试会在远程服务器创建临时目录
   - 单文件上传测试会自动清理
   - 批量上传测试不会自动清理

4. **网络和性能**
   - 大文件测试需要较长时间
   - 批量上传测试会并发执行，注意服务器限制
